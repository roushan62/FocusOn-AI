# FOI-MeetAI — Accuracy Policy (Section 8 mapping)

The guarantee this product actually delivers:

> **100% of what is presented as fact is anchored to the transcript; anything
> the system is not sure of is visibly flagged — never silently wrong.**

True word-perfect transcription of real construction meetings (cross-talk,
site noise, Hinglish) is not physically guaranteeable by any vendor. What is
guarantee-able is *traceability and honest flagging* — implemented as hard
constraints below.

| # | Rule | Where it lives |
|---|---|---|
| 1 | **No fact without a transcript anchor** — every extracted item must carry `sourceTimestamp` + `sourceQuote`; unanchored items are dropped, not guessed | `lib/meetai/prompts.ts` (ACCURACY_POLICY rule 1, baked into every extraction call) |
| 2 | **Independent verification pass** — a second LLM (preferring a different model family: Claude → GPT → Gemini → …) compares MOM JSON against the raw transcript; verdicts are `drop` (removed) or `flag` (kept with `⚠️ Please verify` reason) | `app/api/verify/route.ts` + `runVerification`/`applyVerification` in `lib/meetai/pipeline.ts` |
| 3 | **No invented dates** — relative deadlines are converted against the meeting date AND labelled `(inferred from 'end of week' — confirm exact date)` | prompts rule 2; rendered in `lib/meetai/google/sheets.ts` (Due Date cell) and the PDF |
| 4 | **No invented names** — unidentified owners become `"Unidentified Speaker — confirm owner"`; roster names come from the who's-who form or DOM, never LLM invention | prompts rule 3; `app/api/diarize/route.ts` only assigns roster names |
| 5 | **Confidence scoring** — every row carries High/Medium/Low confidence from transcript clarity, STT confidence and verifier agreement; low-confidence rows are yellow-highlighted in the Sheet (and shown flagged in the dashboard) | `flaggedRow()` in `lib/meetai/google/sheets.ts`; dashboard `meetings/[id]` page |
| 6 | **Disclaimer in every MOM** — "Generated by FOI-MeetAI — verify before circulation" in the Sheet footer, email body and PDF | `MOM_DISCLAIMER` in `lib/meetai/types.ts` |
| 7 | **Raw transcript archive** — Supabase `meet_transcript_segments` + a *hidden* `Transcript_MOM_…` tab in the same spreadsheet; Source Quote column keeps the verbatim evidence next to every row | `lib/meetai/google/sheets.ts` (`archiveTranscript`), `lib/meetai/store.ts` |
| 8 | **Conservative escalations** — Client Concerns populate only on explicit tone/repetition cues with verbatim-close quotes; mild disagreement is not an escalation | prompts rule 4; verifier rule 3 re-checks exaggeration |

## Additional guardrails

- **Domain glossary** (`lib/meetai/glossary.ts`): BOQ, HOD, NCN, ACS, ELV, CCTV,
  PA, DB, MEP, RFI, retention, GF/FF/SF, B.O.S/B.O.B, carpet area, PMC, EPC…
  injected into every prompt so terms are preserved exactly as spoken.
- **Numbers/areas/amounts**: copied verbatim; unclear numbers are quoted with
  `(unclear)` + Low confidence instead of "corrected" by the model.
- **Hinglish**: extraction happens in professional English but `sourceQuote`
  is always verbatim in the original language, so proof survives translation.
- **Provenance footer**: the Sheet footer records exactly which STT / extraction /
  verification providers produced the document — auditable in one glance.

## What the human still does

Read the yellow-flagged rows (usually a handful) against the Source Quote /
hidden transcript tab before circulating. That takes ~2 minutes and is the
professional-CYA workflow used by every serious AI notetaker (Otter, Fireflies,
Fathom all show equivalent disclaimers).
