# Google Sheets MOM Template (built by the API, exact layout)

One spreadsheet per project — **"FocusOn MOM Log — `<Project>`"** — auto-created on
first use (or point the wizard at an existing spreadsheet ID). One tab per meeting:
`MOM_<ProjectName>_<DDMMYY>`. Re-running the same day overwrites that tab.

## Header block (rows 1–3)

| Region | Format |
|---|---|
| `FOCUSON INTERIORS PVT. LTD. — MINUTES OF MEETING` | merged A:H, navy `#1A1F5C` fill, white bold Arial 14, centered, 34px row |
| `Project: …  Meeting Date: …  Duration: hh mm` | light row, bold |
| `Location/Platform: …  Prepared By: …` | light row |
| logo (optional) | `=IMAGE(url)` under the header, right cell |

## Sections (each: navy section bar merged A:H + gold `#C9A227` bottom border; column header row gold fill; Arial 10, wrapped)

1. **ATTENDEES** — `Name | Organization | Role | Email | Note`
   (unconfirmed attendees get `⚠️ unconfirmed attendance` note + yellow)
2. **AGENDA** — single paragraph row (opening-minutes inference, or "Not explicitly stated…")
3. **DISCUSSION TIMELINE** — `Time | Topic | Summary | Screen Context | Source Quote`
   (Screen Context = BOQ / Drawing / Excel / Schedule-Gantt / PPT / RFI / Other as tagged by the vision pass, so the MOM reads "BOQ discussed at 10:22")
4. **DECISIONS** — `# | Decision | Related To | Confirmed By | Source Quote`
5. **ACTION ITEMS** — `# | Owner | Task | Due Date | Priority | Status (default Pending) | Source Quote`
   - Inferred dates carry the `(inferred from '…' — confirm exact date)` note inline
   - **Conditional formatting**: RED fill when `Status="Pending"` and due date ≤ 3 days out; GREEN fill when `Status="Done"`
6. **RISKS** — `# | Risk | Impact Area | Suggested Mitigation (AI Suggestion — confirm with PM) | Source Quote`
7. **OPEN ISSUES** — `# | Issue | Owner | Target Resolution Date | Source Quote`
8. **CLIENT CONCERNS / ESCALATIONS** — `# | Concern (verbatim-close quote) | Severity | Raised By | Timestamp`
   (conservative — only explicit tone/repetition signals)
9. **COMMITMENTS MADE** — `# | Who | Promised | Source Quote`
10. **NEXT MEETING** — stated date/time, else `Not scheduled — confirm with client.`

## Footer row

`Generated by FOI-MeetAI — verify before circulation · Generated <IST timestamp> · Providers: STT=… / MOM=… / Verify=…`

## Flag rendering (accuracy policy)

- `verificationFlag` set or `confidence = Low` → **yellow row highlight** + `⚠️ Please verify — <reason>` prefix in the cell
- Unconfirmed attendees → note column + yellow
- Every extracted row shows its **Source Quote** column — evidence is one cell away

## Hidden tab

`Transcript_MOM_<Project>_<DDMMYY>` — one transcript line per cell (`[mm:ss] Speaker: text`),
hidden from normal view (right-click → Unhide when auditing). This is the 2-minute
manual-verification path for any flagged row.

---

### Building the same template by hand (starter copy)

If you want a styled starter spreadsheet before the first automated run, create a
spreadsheet with the tabs above and copy the header/section styling using the hex
codes (`#1A1F5C` navy, `#C9A227` gold, Arial). The API-created tabs match this spec
programmatically in `lib/meetai/google/sheets.ts` — treat that file as the source of truth.
