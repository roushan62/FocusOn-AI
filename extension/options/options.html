FOI-MeetAI — Setup Wizard

One-time setup for FocusOn Interiors. No code, no terminal — paste keys, test, save. The system runs with any ONE working provider; every extra key adds reliability through the fallback chain.

Step 1 — Backend connection

URL of the deployed FocusOn AI backend (the Vercel app in this repository).

Step 2 — Company profile (auto-fills every MOM header)

Step 3 — Speech-to-Text API keys free tiers available

Fallback chain: Groq Whisper → Deepgram → AssemblyAI → OpenAI Whisper → Google STT → local whisper.cpp. Any one key works.

Step 4 — LLM API keys (MOM generation + verification)

Fallback chain: Gemini → Groq → OpenRouter → Claude → GPT-4o → DeepSeek → Ollama (local). Verification prefers a different model family automatically.

Step 5 — Meeting defaults

Google sign-in (Sheets + Gmail draft)

  1. Create one OAuth client (Chrome Extension type) in Google Cloud Console using this extension ID, and paste it into manifest.json → oauth2.client_id. Detailed 5-minute guide: docs/SETUP.md.
  2. The first time you stop a meeting, Chrome asks you to sign in — that's the only permission prompt you'll ever see.
  3. Sheets scope writes your MOM; Gmail scope only ever creates drafts (nothing is ever auto-sent).
